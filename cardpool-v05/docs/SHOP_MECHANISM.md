# 商店机制与本项目能访问的数据

检查范围：V0.5/V0.6源码中的输入来源、游戏通信接口、屏幕采集时序与概率计算路径。项目未接入游戏协议或游戏服务端 API，没有 ROOT、进程注入、内存读取或隐藏商店接口。没有进行协议逆向或声称已验证专有客户端/服务器协议。

MediaProjection 取得用户已授权、客户端已经显示的像素。OCR和模板匹配发生在画面渲染之后，因此只能描述已经可见的这一店。对未展示的下一轮商店，本项目没有真实可访问的数据来源。即使一段画面上英雄名识别置信度很高，也不能解释为对下一轮结果的置信度。

通常刷新结果需游戏逻辑处理后由客户端展示；具体游戏版本的服务端生成时机、隐藏缓存、随机种子及协议字段在本项目中均未得到验证。不能从当前截图推断这些隐藏状态，也不会伪造五张下一店英雄。

实现仅提供两种独立信息：

- `CaptureData` 中带时间和识别置信分的当前/历史可见商店观察；不计为已购买持牌。
- `Prediction` / C++ JNI 中按人工配置的费用概率和估算剩余卡池计算的概率分布；不是下一店结果。

未观察玩家、备战席、出售、隐藏特殊机制以及已过期的历史记录都会导致估算误差。用户应核对规则，并在必要时修正记录。
