# V0.6.6 英雄联盟传奇（非 ROOT）· 等级刷新概率参考配置

版本目的：解决「概率没有配置」导致 APP 不能显示各费用刷新比例的问题。请注意「1～5 费费用概率」和「具体英雄的个人概率」**不是一回事**。

## 操作

- 安装 V0.6.6 后进入「卡池统计」。
- 先加载候选英雄 OCR 字典（若需要）；再点击「一键配置：1～11级商店费用概率（版本可选）」。
- 选择 **16.4 调整后** 或 **16.4 调整前**，按你手机当前对局规则/游戏内概率页面核对；各等级数据会被记录在本地，不需要 ROOT。
- 进入「商店预测」，显示玩家当前等级的 1～5 费参考概率。若玩家等级未知，可在八人数据界面手动填写等级。自定义时可通过「配置刷新规则」修改。

## 不能误算的部分

- APP 的 119 条英雄信息是辅助 APK Set16 的候选目录再加新增单位，不是已核实的完整商店名单，含有非普通商店单位。
- 完整英雄卡池总张数、正确所属费用档、玩家逐个解锁状态、解锁后商店最右栏位、弃用权重衰减及已观察持牌数量尚未完全获证。
- 英雄联盟传奇可能按解锁条件动态改变可抽英雄、个性化权重；金边 6、7 费不能当作普通 5 费英雄进行简单预测。
- 因此**本版本只显示按等级的费用概率，不声称已核实特定英雄的完整出现概率**。就算用户勾选「名单已核实」，程序仍不提供不可靠的英雄命中率。
- 切换赛季导入 CSV 时，自动清空先前的各等级商店赔率，避免旧赛季赔率误用；不会删除持牌记录。
- 实际对局中的经验频率可在「采集 → 导出已观察的商店变化 CSV」查看，它不是官方概率，更不能预知下一次随机刷新。
