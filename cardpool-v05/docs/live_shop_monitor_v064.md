# V0.6.4 · 英雄联盟传奇 normal · 实时商店观察

这是**实时屏幕观察工具**，不是游戏进程内存扫描器。仅在用户授权 Android 系统屏幕捕获之后读取可见图像，使用本地 OCR/模板匹配，不注入游戏进程，不读取服务器卡池或未来随机数。

## 运行方式

1. 安装 APK 后，在「卡池统计」选择「导入：英雄联盟传奇普通模式（候选OCR名单）」。当前 119 条条目是**候选识别字典**，不是经过核实的完整商店名单；部分含特殊弈子和人工占位 ID。
2. 在「采集 → 校准识别区域与8名玩家别名」选择对应游戏屏幕的长宽比和每张商店卡片文字区域；先用「验证一张截图（不写入对局）」检查识别。
3. 如果商店界面遮挡了玩家名，使用「绑定当前商店归属玩家（仅五张棋子）」；绑定不允许修改该玩家的生命/金币/棋盘数据。
4. 点击「开始：请求系统屏幕捕获授权」，同意系统提示，再切回游戏。
5. 当**五格均在同一帧经过连续两帧高置信确认**并与该玩家上一个完整五格样本不同时，保存一条本地观察事件；若没有显示全部五格，或有一格识别失败，则不保存该组。相同五格多次出现只记一次。
6. 在「采集」页查看不同商店记录数、各费用出现占比、英雄出现次数及相邻完整观察的英雄重合数。可以通过系统文件选择器导出 CSV（可用 MT 管理器、表格软件查看）；新对局可清空观察历史。

## 数据解释

- 一次**可见商店变化**不一定对应一次付费刷新，也可能是系统自动换店或特殊效果；相邻两条观察记录之间可能漏掉多个商店。
- 数据仅反映所观察、所成功识别的画面，受观看选择、识别成功率、解锁条件等影响，有选择偏差。展示的经验频率不是**官方刷新概率**，不能保证下次刷到哪张。
- 此版本尚未确认英雄联盟传奇全部实际英雄/卡池张数和每等级刷新表，也未实现解锁英雄、固定商店槽位或7费的准确概率模型。**正式概率预测维持停用**。
- 商店卡牌只是可出售的当前商品，不能据此将它们扣除为玩家持牌；实际持牌需要手动记录或经授权的棋盘识别结果。
- 历史只保存最新 160 组完整事件，按当前赛季标签/ID过滤，数据不上传网络，也不存储截图。
